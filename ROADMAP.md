# Cybersecurity Learning Roadmap

This roadmap is organized by phases, not by days.

Each phase builds on the one before it. Move at your own pace.

## Phase 1: Digital Confidence

Goal: Stop feeling intimidated by technology.

Topics:

- What cybersecurity means
- Why basic tech skills matter
- Common beginner fears
- How to learn without getting overwhelmed

## Phase 2: Computer and Hardware Basics

Goal: Understand what a computer is doing under the hood.

Topics:

- CPU
- RAM
- Storage
- Operating systems
- USB drives
- Wi-Fi adapters
- Routers
- Phones and laptops

## Phase 3: Linux Basics

Goal: Learn how to move around and use basic Linux commands.

Topics:

- What Linux is
- Why cybersecurity uses Linux
- Terminal basics
- Files and folders
- Basic commands
- Permissions

## Phase 4: Networking Basics

Goal: Understand how devices communicate.

Topics:

- IP addresses
- Routers
- DNS
- Ports
- Packets
- LAN vs WAN
- Wi-Fi basics

## Phase 5: Internet Traffic

Goal: Understand what happens when devices send and receive data.

Topics:

- HTTP and HTTPS
- Requests and responses
- Browser traffic
- DNS lookups
- Packets
- Basic traffic observation

## Phase 6: Cybersecurity Fundamentals

Goal: Understand the basic ideas behind security.

Topics:

- Threats
- Vulnerabilities
- Risk
- Password security
- Updates
- Malware
- Phishing
- Safe browsing

## Phase 7: OPSEC and Privacy

Goal: Learn how to protect personal information.

Topics:

- What OPSEC means
- Digital footprints
- Account security
- Two-factor authentication
- Public Wi-Fi risks
- Social media exposure
- Device privacy settings

## Phase 8: AI and Modern Tools

Goal: Understand how AI fits into modern learning and security.

Topics:

- What AI can help with
- What AI should not be trusted with
- Prompting basics
- Fact-checking AI answers
- Using AI as a learning assistant

## Phase 9: Practice Labs

Goal: Apply what you learned safely.

Topics:

- Basic Linux practice
- Simple networking checks
- Reading logs
- Safe beginner labs
- TryHackMe-style practice
- Documentation habits

## Phase 10: Reflection and Resource Library

Goal: Review what was learned and collect useful resources.

Topics:

- What improved
- What was confusing
- What to study next
- Recommended books
- Recommended websites
- Recommended tools
