# Notes

This folder is for working notes, rough ideas, research notes, and questions.

These notes do not need to be perfect.

Use this folder to collect ideas before turning them into clean guide sections.

## Note Format

Use this simple format:

# Topic

## What I Learned

## What Confused Me

## Questions

## Sources To Check

## How This Could Improve The Guide

## Rule

Notes are allowed to be messy.

The final guide should be clean.
