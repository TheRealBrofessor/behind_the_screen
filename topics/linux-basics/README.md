# Linux Basics

## Goal

The goal of this section is to introduce Linux in a simple and practical way.

Linux is heavily used in cybersecurity, servers, networking, cloud systems, and technical troubleshooting.

## What You Will Learn

- What Linux is
- Why cybersecurity uses Linux
- What the terminal is
- How files and folders work
- Basic Linux commands
- Why permissions matter
- How to practice safely

## Beginner Explanation

Linux is an operating system.

An operating system is the main software that controls a computer and lets you interact with files, programs, hardware, and networks.

Cybersecurity often uses Linux because it is powerful, flexible, open, and common on servers and security tools.

The terminal is a text-based way to control the computer.

Instead of clicking buttons, you type short instructions called commands.

This may look intimidating at first, but beginner Linux commands are mostly simple instructions for moving around, listing folders, and reading files.

Linux is not about memorizing everything.

It is about learning how to ask the system clear questions and understand the answer.

## Basic Commands

pwd: Shows your current location.

ls: Lists files and folders.

cd: Changes folders.

mkdir: Creates a folder.

touch: Creates a file.

cat: Shows the contents of a file.

clear: Clears the terminal screen.

## Why This Matters

Many cybersecurity tools run on Linux.

Many servers use Linux.

Many logs, scripts, tools, and security labs require basic Linux knowledge.

You do not need to be an expert at first.

You need to understand how to move around, view files, create files, and read basic output.

## Basic Activity

Open a terminal and practice these beginner commands one at a time:

- pwd
- ls
- mkdir practice-folder
- cd practice-folder
- touch notes.txt
- ls
- cat notes.txt

After each command, write down what changed on the screen.

## Beginner Warning

Do not copy random Linux commands from the internet without understanding what they do.

Some commands can change files, change permissions, or affect system settings.

When unsure, look up the command first.

## Key Takeaway

Linux is a skill built through repetition.

Start with simple commands.

Learn what they do.

Practice slowly.
