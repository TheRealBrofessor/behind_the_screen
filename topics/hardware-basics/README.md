# Computer and Hardware Basics

## Goal

The goal of this section is to help beginners understand the basic parts of a computer and what those parts do.

Cybersecurity becomes easier to understand when you know what a device is made of and how the main parts work together.

## What You Will Learn

- What a computer is
- What the CPU does
- What RAM does
- What storage does
- What an operating system does
- Why hardware matters in cybersecurity
- How common devices store and move information

## Beginner Explanation

A computer is a machine that receives information, processes it, stores it, and sends information back out.

The CPU is the part that handles instructions.

RAM is short-term memory. It helps the computer work on things that are currently open.

Storage is where files, programs, and the operating system are saved.

The operating system is the main software that lets you use the computer. Windows, macOS, Linux, Android, and iOS are all operating systems.

Hardware matters in cybersecurity because every device can store information, connect to networks, and become a target if it is not protected.

Phones, laptops, routers, USB drives, printers, smart TVs, and tablets are all computers in some form.

## Important Hardware Terms

CPU:
The processor. It runs instructions.

RAM:
Temporary working memory. It helps the device handle active tasks.

Storage:
Long-term file storage. This is where documents, apps, photos, and system files are saved.

Operating System:
The main software that controls the device.

Router:
The device that connects your local network to the internet.

Wi-Fi Adapter:
The part that lets a device connect wirelessly.

USB Drive:
A small storage device that can move files between computers.

## Why This Matters

Cybersecurity often starts with knowing what device you are dealing with.

A laptop, phone, router, and USB drive all have different risks.

For example:

- A lost phone can expose messages, photos, and accounts.
- A weak router password can expose a home network.
- A USB drive can carry files or malware.
- An outdated laptop can have unpatched vulnerabilities.

Understanding hardware helps you ask better security questions.

## Basic Activity

Look at one device you use every day.

Write down:

1. What kind of device is it?
2. Does it connect to Wi-Fi?
3. Does it store personal information?
4. Does it have updates?
5. Does it require a password, PIN, fingerprint, or face unlock?
6. What would happen if you lost it?
7. What would happen if someone else could access it?

## Key Takeaway

Hardware is the physical side of technology.

Cybersecurity becomes easier when you understand what each device does, what information it holds, and how it connects to other systems.
