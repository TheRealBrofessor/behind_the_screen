# Internet Traffic

## Goal

The goal of this section is to help beginners understand what happens when devices send and receive information online.

## What You Will Learn

- What internet traffic means
- What HTTP and HTTPS are
- What requests and responses are
- What browser traffic is
- What DNS lookups are
- Why traffic matters in cybersecurity
- How to think about online communication

## Beginner Explanation

Internet traffic is the information moving between devices.

When you open a website, your device sends a request.

The website sends back a response.

That back-and-forth communication is traffic.

HTTP and HTTPS are ways that browsers and websites communicate.

HTTPS is more secure because it uses encryption.

DNS lookups happen when your device tries to find the IP address for a website name.

Cybersecurity often involves understanding traffic because suspicious activity usually leaves signs in communication patterns.

You do not need to understand every packet at first.

Start by understanding that devices are constantly asking for information, receiving information, and creating records of that communication.

## Important Terms

Request: A message your device sends asking for something.

Response: A message sent back to your device.

HTTP: A web communication protocol.

HTTPS: A more secure web communication protocol that uses encryption.

Browser: The app used to access websites.

DNS Lookup: The process of finding the IP address for a website name.

Traffic: The data moving between devices.

## Why This Matters

Internet traffic can reveal important security information.

Defenders look at traffic to find:

- Suspicious connections
- Strange login activity
- Unusual downloads
- Repeated failed attempts
- Connections to unknown systems

Beginners do not need to inspect advanced traffic right away.

The first step is understanding that online activity creates communication.

## Basic Activity

Open a web browser and visit three websites.

For each one, write down:

1. What website did I visit?
2. Did the address begin with HTTPS?
3. Did the site ask for a login?
4. What personal information would be risky to enter on this site?
5. Did the site load images, ads, videos, or scripts?
6. Would I trust this site with sensitive information?

## Key Takeaway

Internet traffic is the movement of data.

Cybersecurity often depends on understanding what is communicating, where it is going, and whether it looks normal.

## Notes

Write down anything confusing about websites, browsers, or traffic.
