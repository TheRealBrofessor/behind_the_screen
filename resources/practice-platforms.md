# Practice Platforms

This file is for safe cybersecurity learning platforms.

## Purpose

Practice platforms give beginners a safe place to learn with clear rules and permission.

## Platform Categories

- Beginner cybersecurity labs
- Linux practice
- Networking practice
- Web security practice
- Blue team practice
- Capture-the-flag practice

## Safety Rule

Only use platforms that clearly allow training and practice.

Do not test random websites, public systems, or networks you do not control.
