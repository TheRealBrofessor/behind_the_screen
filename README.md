# Behind the Screen

**Behind the Screen** — a structured cybersecurity learning repo by **TheRealBrofessor**.

It's a beginner-friendly, 10-phase roadmap covering:

1. Digital Confidence
2. Hardware Basics
3. Linux Basics
4. Networking Basics
5. Internet Traffic
6. Cybersecurity Fundamentals
7. OPSEC & Privacy
8. AI & Modern Tools
9. Practice Labs
10. Reflection & Resources
