# Codex Notes: Behind the Screen

Use this project style when adding lessons:

- Keep beginner explanations short and practical.
- Use plain language before technical terms.
- Add a safe local lab when possible.
- Avoid exploit steps or instructions against third-party systems.
- Prefer Markdown lessons under `lessons/`.
- Prefer simple helper scripts under `tools/`.
- Keep README clean and use it as the front door.

## Suggested Lesson Pattern

1. Simple explanation
2. What the learner should understand
3. Key terms
4. Safe commands
5. Beginner lab
6. What to remember

## Design Direction

The project voice should feel direct, practical, and human, without sounding like a bootcamp sales page.
