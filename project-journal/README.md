# Project Journal

This folder is for tracking project progress.

This is separate from the reader-facing guide.

Use this folder to document what was built, changed, researched, or improved.

## Why This Exists

The guide is for the reader.

The journal is for the project record.

This separation keeps the public guide clean while still showing the work behind it.

## Journal Format

Each entry should include:

- What was built
- What changed
- What was learned
- What problems came up
- What needs to happen next
