# Week 01 Project Journal

## What I Built

- Created the main Owlsec project folder.
- Created the Behind the Screen project.
- Created the beginner cybersecurity roadmap structure.
- Added the main README, mission, start page, and roadmap.
- Created topic folders for the learning guide.
- Started the first beginner topic: Digital Confidence.
- Connected the project to GitHub.
- Published the project as a GitHub Pages site.

## What I Decided

- The project will use phases instead of days.
- The project will be self-paced.
- The project will avoid strict bootcamp language.
- The guide will focus on confidence, understanding, and practical learning.
- The reader-facing guide will stay separate from project documentation.
- The title is Behind the Screen.
- The subtitle is One Man's Journey, Another Person's Guide.

## What I Learned

- A project folder needs structure.
- GitHub repos are easier to understand when files are clearly organized.
- Markdown can be used to build a readable guide.
- GitHub Pages can turn the repo into a static website.
- A beginner guide needs a clear entry point.

## Problems I Ran Into

- The local folder path was different from the Desktop path.
- README.md was accidentally overwritten while using cat.
- Git had to be initialized before pushing.
- GitHub required authentication before accepting the push.
- The site worked, but the content needed better structure.
