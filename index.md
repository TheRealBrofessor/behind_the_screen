  <h1>Behind the Screen</h1>
  <h2>One Man's Journey, Another Person's Guide</h2>

  <p>A practical cybersecurity learning journey for people who thought they were too late to learn modern technology.</p>

  <p>This project breaks down cybersecurity, Linux, networking, hardware, internet traffic, AI awareness, and basic OPSEC into clear beginner-friendly lessons.</p>

  <p>The goal is not to rush. The goal is to build confidence one concept at a time.</p>

  <div>
    <p class="section-label">Purpose</p>
    <h2>What This Project Is</h2>
    <p>This is a self-paced cybersecurity learning guide built for beginners.</p>
    <p>It is designed to help everyday people understand modern technology without pressure, confusion, or technical gatekeeping.</p>
  </div>

  <div>
    <p class="section-label">Boundaries</p>
    <h2>What This Project Is Not</h2>
    <p>This is not a strict daily challenge.</p>
    <p>This is not a bootcamp.</p>
    <p>This is not a timed course.</p>
    <p>This is a learning path that can be followed one concept at a time.</p>
  </div>
